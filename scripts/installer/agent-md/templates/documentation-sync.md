## Documentation Sync

When a change affects documented behavior (API, package, toolchain, structure), check `docs/wiki/` (start at `docs/wiki/index.md`) and any relevant `README.md`, and update them — docs must never contradict the codebase. See [Documentation Sync skill](.claude/skills/documentation-sync/SKILL.md) for the step-by-step procedure.

Keep every wiki page LLM Wiki style: atomic, one concept per page, minimal. Soft cap ~400 lines, hard cap 800 — split into another page instead of growing past that.
